# Firebase 설정 (폰 또는 PC, 카드 등록 없음)

Firebase는 가족 데이터를 저장하는 곳(Firestore)으로만 씁니다. **무료 Spark 요금제**로 충분하며 카드를 요구하지 않습니다.
아이폰 Safari에서 해도 되지만, 화면이 작으면 주소창 왼쪽 `ぁ가` → **데스크탑 웹 사이트 요청**을 누르면 편합니다.

## 1. 프로젝트 만들기
1. Safari에서 `console.firebase.google.com` 접속 → Google 계정으로 로그인.
2. **프로젝트 만들기**(또는 "프로젝트 추가") 탭.
3. 이름 입력 (예: `family-board-xxxx`, 영문 소문자·숫자·하이픈) → **계속**.
4. "Gemini/Google 애널리틱스" 질문이 나오면 **끄기** → **프로젝트 만들기** → 완료되면 **계속**.

## 2. Firestore 데이터베이스 만들기
1. 왼쪽 메뉴(☰) → **빌드** → **Firestore Database** → **데이터베이스 만들기**.
2. 에디션/모드를 물으면 **Standard(표준)** 를 고릅니다.
3. 위치: **asia-northeast3 (Seoul)** → **다음**.
4. 보안 규칙: **프로덕션 모드로 시작** → **만들기**. (규칙은 아래 3번에서 바로 교체합니다)

## 3. 보안 규칙 붙여넣기 (가장 중요)
1. Firestore Database 화면 위쪽 탭 **규칙** 탭.
2. 기존 내용을 전부 지우고 저장소의 `firestore.rules` 파일 내용을 그대로 붙여넣기.
   (GitHub에서 `firestore.rules` 파일을 열고 오른쪽 위 복사 아이콘을 누르면 전체가 복사됩니다.)
3. **게시** 탭. "게시됨"이 보이면 완료.

이 규칙은 "가족 코드(28자리 랜덤)를 아는 기기만 읽고 쓰기, 코드 없이 목록 보기는 불가"입니다.

## 4. 웹 앱 등록하고 설정값 복사
1. 왼쪽 위 **프로젝트 개요** 옆 톱니바퀴 → **프로젝트 설정**.
2. 아래쪽 **내 앱**에서 웹 아이콘 **`</>`** 탭.
3. 앱 닉네임 입력 (예: `board`). **"Firebase Hosting도 설정"은 체크하지 않습니다.** → **앱 등록**.
4. 화면에 `const firebaseConfig = { apiKey: "...", ... };` 가 나옵니다. **중괄호 `{ … }` 부분 전체**를 길게 눌러 복사합니다.
5. 이 값은 비밀번호가 아니라 "주소" 같은 공개 값이지만, 코드에는 넣지 않고 GitHub 변수로만 넣습니다 → `DEPLOY-GITHUB-PAGES.md` 3번.

## 5. 무료 한도 확인 (선택)
Spark 요금제 하루 한도는 읽기 5만 / 쓰기 2만 회입니다. 가족 4명이 쓰기에는 훨씬 넉넉합니다.
왼쪽 아래에 **Spark(무료)** 라고 표시돼 있으면 카드가 연결되지 않은 상태입니다. **업그레이드 버튼은 누르지 마세요.**
