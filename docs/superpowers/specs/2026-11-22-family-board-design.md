# 우리집 보드 — 설계 문서

> 이 저장소는 Public(공개)로 쓰므로 가족 이름, 근무 데이터, 가족 코드를 코드·문서·테스트에 넣지 않는다.
> 구성원 이름은 앱 설정 화면에서 입력해 Firestore에만 저장한다.

## 목적
가족 4명(어른 2명, 아이 2명)만 쓰는 상태 공유 보드. 아이폰 Safari "홈 화면에 추가"로 쓰는 PWA, 거실 아이패드(가로)는 보드 모드. 참고 앱의 분위기와 기능 구성만 참고하고 이름·캐릭터·그림은 새로 만든다.

## 목표 / 비목표
- 목표: 비용 0원(카드 등록 없음), 한국어 UI, 모바일 우선, 5세도 쓰는 그림 버튼 중심, 48px 이상 터치 영역, 실시간 동기화.
- 비목표: 앱스토어, 위젯, 푸시 알림(2차), 위치 자동 추적, 외부 공유.
- 안티골: 카드 등록이 필요한 서비스, 공개 코드에 개인정보, 다른 직원 근무 정보 저장.

## 제약과 결정
- 데이터: Firebase Spark(Firestore만). 호스팅: **GitHub Pages**(Public 저장소, GitHub Actions 자동 배포, `main` 기준).
- Firebase 설정값(`VITE_FIREBASE_CONFIG`)은 저장소 변수로 주입한다. 비밀은 아니지만 코드에 박지 않는다.
- 접근 제어: `families/{긴 랜덤 코드}/…` 경로 + 보안 규칙(목록 조회 차단). 가족 코드는 URL 해시(`#c=`)로 공유해 서버 로그에 남지 않는다.
- 부모 PIN(4자리): 유튜브 응답, 설정, 근무표 화면에 들어갈 때만 묻고, 한 번 입력하면 그 기기에서 30분 유지. PIN은 SHA-256(가족 코드 + PIN) 해시로 Firestore 설정에 저장한다. 4자리는 강한 보안이 아니라 아이의 실수 방지용 잠금이다.
- 하단 탭 `오늘·상태·한마디·루틴·더보기`, 더보기에 `일정·달력·근무·설정·거실 보드`. 시간대는 Asia/Seoul. 루틴은 `routines/{YYYY-MM-DD}` 날짜별 문서(자정 리셋 불필요).

## 접근 비교
| 접근 | 판단 |
|---|---|
| React+Vite+Firestore + GitHub Pages | **선택**: 무료, 배포 자동, 카드 불필요 |
| Cloudflare Pages / Netlify | 가능하나 계정이 하나 더 필요(Netlify는 배포 한도 위험) |
| Firebase Hosting | PC에서 CLI 배포 필요 |

## 단계
0 뼈대·Firebase 연결·배포·가족 코드·나는 누구·PIN → 1 오늘·상태·한마디·루틴 → 2 일정·달력 → 3 근무 가져오기 → 4 거실 보드·PWA.
단계마다 폰에서 확인 방법을 안내하고, 동작과 테스트를 확인한 뒤 브랜치에 푸시한다.

## 빌더 판단에 맡기는 것
세부 UI 배치, 이모지 선택, 보조 색상, 컴포넌트 분할, 아이콘 디자인.
