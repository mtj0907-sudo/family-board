# 알림 켜기 (무료, 카드 등록 없음)

아이가 한마디를 보내거나, 유튜브를 물어보거나, 가족이 상태를 바꾸면 **폰에 알림**이 오게 합니다.
이를 위해 아주 작은 **알림 서버**를 한 번 만들어야 해요. Cloudflare의 무료 플랜을 쓰며 카드는 필요 없습니다.

> 화면 이름은 Cloudflare가 바꿀 수 있어서 조금 다를 수 있어요. 비슷한 이름의 메뉴를 찾으면 됩니다.
> 아이폰 Safari에서 하다가 화면이 좁으면 주소창 왼쪽 `ぁ가` → **데스크탑 웹 사이트 요청**을 누르세요.

## 알아 둘 점
- **아이폰은 iOS 16.4 이상**이고, 앱을 **홈 화면에 추가**해서 그 아이콘으로 열었을 때만 알림을 켤 수 있어요. (Safari 탭에서는 안 됩니다.)
- 알림 서버는 **데이터를 저장하지 않고**, 따로 넣는 비밀번호도 없어요. 가족 코드 아래의 알림 받는 기기 목록만 읽어서 푸시를 보냅니다.
- 알림 키는 앱 설정에서 만들어 가족 설정에 저장돼요. 가족 코드를 아는 사람만 읽을 수 있습니다.
- 무료 플랜은 하루 10만 번까지 쓸 수 있어서, 가족이 쓰기에는 훨씬 넉넉해요.

## 1. Cloudflare 가입 (이미 있으면 로그인)
1. Safari에서 `dash.cloudflare.com` 접속 → **Sign up** → 이메일·비밀번호 입력 → 메일 인증. 카드 입력은 없습니다.

## 2. 알림 서버 만들기 (GitHub 저장소 연결)
1. 왼쪽 메뉴(☰)에서 **Workers & Pages**를 누릅니다.
2. **Create**(또는 "애플리케이션 만들기")를 누르고, **Import a repository**(또는 "Connect to Git")를 고릅니다.
3. **GitHub**를 연결합니다. 허용 창에서 **Only select repositories** → `family-board` 하나만 선택하고 **Install**을 누릅니다.
4. 목록에서 `family-board`를 선택하고 **Next**(또는 Begin setup)를 누릅니다.
5. 아래처럼 입력합니다.
   - **Project name / Worker name**: `family-board-push` (그대로 두세요. 다르면 배포가 실패할 수 있어요.)
   - **Root directory**(또는 "경로"): `/worker`
   - **Build command**: 비워 둡니다.
   - **Deploy command**: `npx wrangler deploy` (기본값 그대로)
6. **Save and Deploy**를 누릅니다. 1~2분 기다립니다.
7. 처음이면 "workers.dev 하위 도메인"을 정하라고 해요. 영문 소문자로 아무 이름이나 정하면 됩니다.

## 3. 주소 확인
1. 완료되면 `https://family-board-push.(내 이름).workers.dev` 같은 주소가 보입니다. 이 주소를 복사하세요.
2. 그 주소를 Safari 새 탭에 붙여넣어 엽니다. **`family-board push ok`** 한 줄이 보이면 성공이에요.

## 4. 앱에 연결 (가족에서 한 번만)
1. 부모 폰에서 **더보기 → 설정**(PIN)을 엽니다.
2. **알림** 카드의 칸에 위 주소를 붙여넣고 **알림 서버 연결하기**를 누릅니다.
3. "알림 서버를 연결했어요"가 나오면 끝입니다.

## 5. 기기마다 알림 켜기
알림을 받을 **부모 폰마다** 아래를 해 주세요. (아이패드 거실 보드는 화면에 크게 뜨니 필요 없어요.)
1. 앱을 **홈 화면에 추가**한 아이콘으로 엽니다. (더보기 → 홈 화면에 추가하는 방법)
2. **더보기 → 설정 → 알림**에서 받고 싶은 알림을 고릅니다.
   - 아이의 한마디, 유튜브 요청과 답 (기본 켜짐)
   - 데리러 갈 사람이 바뀔 때 (기본 켜짐)
   - 가족이 상태를 바꿀 때 (자주 와서 기본 꺼짐)
3. **이 기기에서 알림 받기**를 누르고, 나오는 창에서 **허용**을 누릅니다.
4. **시험 알림 보내기**를 누르면 잠시 뒤 "알림이 잘 와요"가 도착합니다.

## 잘 안 될 때
| 증상 | 확인할 것 |
|---|---|
| "이 주소에서 알림 서버를 찾지 못했어요" | 주소가 `https://`로 시작하고 `workers.dev`로 끝나는지, Safari에서 열었을 때 `family-board push ok`가 나오는지 |
| 알림 버튼이 안 보이고 "홈 화면에 추가한 앱에서만…"이 나와요 | Safari 탭이 아니라 **홈 화면 아이콘**으로 열었는지, iOS가 16.4 이상인지 |
| "알림이 막혀 있어요" | 아이폰 **설정 → 알림 → 우리집(앱 이름)**에서 알림 허용 |
| 시험 알림이 안 와요 | **이 기기 알림 끄기**를 누르고 다시 켜 보기. 그래도 안 되면 앱을 홈 화면에서 지웠다가 다시 추가 |
| 내가 한 동작의 알림이 내게는 안 와요 | 정상이에요. 알림은 **다른 기기**로만 가요 |

## 서버를 바꾸거나 지우고 싶다면
- 앱: 설정 → 알림 → **알림 서버 연결 끊기**
- Cloudflare: Workers & Pages에서 `family-board-push`를 열고 설정에서 삭제
